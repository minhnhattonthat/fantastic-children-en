# Skill gotchas

One line per gotcha: the skill reference it belongs in, then the fact.

- scripts/fetch_emu.py / references/setup.md: `fetch_emu.py gba-bios` 404s: retrobios renamed the file to `bios/Nintendo/Game Boy Advance/GBA_bios.rom` (same SHA-1 300c20df6731a33952ded8c436f7f186d25d3492). Downloaded by hand to tools/mesen/Firmware/gba_bios.bin.
- scripts/tbl.py: `Table.decode` runs until an `{end}`/`{goto}` name; a game whose page-end code carries data in its low bits (here `0x8000|count`, 23 codes) needs its own page splitter (tools/dec.py) or a generic "stop on any code matching a mask" option.
- references/graphics.md §Survey: big "unknown packed" regions may be PCM audio, not custom-compressed graphics: a byte-delta statistic (share of |b[i]-b[i-1]| < 24 as signed bytes; PCM 0.6-1.0, packed data ~0.1-0.5) sorted 1.3 MB here in one step (`tools/rommap.py` + note in docs/re/graphics.md). Also: 1D-mapped sprite banks read as diagonal noise at any fixed tiles-per-row; cover them by VRAM capture, not by static sheets.
- scripts/emu.py / references/emulator-qa.md §emu.py: Mesen keeps the GBA battery file per ROM *file name* in `tools/mesen/Saves/`, and `--sav` copies into that same shared path, so parallel runs of one ROM share (and race on) one save; a run whose route saves in game turns NEW GAME into a loaded game for the next runs. Fix used here: each parallel run gets a uniquely named ROM copy plus `--sav` blank (tools/debug/warp_all.py). emu.py could do this itself for parallel Mesen runs.
- scripts/lua/mesen_lib.lua / emulator-qa.md §Hooks: Mesen 2.2 Lua has `emu.read16/read32/write16/write32` but no `emu.write8`/`read8` (use `emu.read`/`emu.write`); `emu.getScreenBuffer()` gives the frame as 240-wide ints, enough for an in-Lua "screen is flat" test so a warp shoots after a fade instead of at a fixed frame.
- SKILL.md / emulator-qa.md: with the context-mode plugin, reading a >~40-line disassembly or log in one go gets indexed away; read in chunks of <=50 lines with offset/limit.
- references/emulator-qa.md §Debug tool: a full warp batch (hours, ~590 MB per Mesen) on a machine shared with other agents' emulators gets reaped by Claude Code's low-memory guard while the session idles (twice here, at 41 and ~407 of 534 scenes), and the harness then forbids restarting it unasked. Make batch verifiers resumable (`warp_all.py --resume` keeps scenes already ok, `--check-only` grades what exists) so a reaped run loses nothing.
- references/emulator-qa.md §Debug tool: a scene list built from static script ranges (split at the end marker) gets wrong expectations: conditional jumps, `next` jumps and choice-answer targets cross ranges, so 46 of 409 event scenes "failed" while the warp was fine. Walk the record flow (both ways at each condition, choice targets too) to list a scene's messages, and force the first condition's flag toward the script's own text.
- references/emulator-qa.md §Debug tool: the low-memory reap can be dodged without restarting Claude Code: launch the batch detached (`Start-Process python ... -WindowStyle Hidden -RedirectStandardOutput log`) and watch it with a Monitor polling `tasklist` for the PID; 497 scenes ran to the end that way at --jobs 2 (~8 scenes/min).
- references/emulator-qa.md §Debug tool: a "shoot N frames after the message fetch" rule needs a per-scene override: a test event that fades in slowly was still near-black at fetch + 60 (`warp.lua textwait=`).
- references/pipeline.md §Marker / engine spike: when the copy into the line buffer caps codes per line (here 22) and widening the RAM buffers means patching many offsets, pack two characters per 16-bit code (a flag bit + two 7-bit glyph indices, avoiding bit patterns the copy routine treats as control codes) and let the VWF hook unpack them: no buffer, reveal or copy changes. The typewriter then reveals two letters per step.
- references/pipeline.md §Marker: a VWF hook in a routine the game re-runs every frame (re-type the shown part, then blank-fill "the rest" from x+count) must keep that fill off the extra cells the proportional text maps, and must clear/blank every cell a previous, longer line used; stale cells showed up only in typewriter frames, so shoot every 20 frames, not just the settled box.
- references/emulator-qa.md §emu.py: manual emu.py runs of the same ROM file share Mesen's battery save too (not only parallel runs): after one run mashed through a save prompt, later cold-boot warps loaded that save and went somewhere else. Pass `--sav <blank.sav>` on every manual run.
- references/pipeline.md §Marker: a game can pick a different font per box with a different background value (here font 1 has background 1 = opaque black, font 0 has 0 = transparent); a VWF that clears cells to 0 shows the scene through the top box. Check the original tiles' background value per box.
