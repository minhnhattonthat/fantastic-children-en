# Fantastic Children (GBA) English translation

Skill: translate-retro-game (Claude Code: plugin, enabled in .claude/settings.json; other agents: `<SKILL_DIR>/SKILL.md`; `$SKILL` = the directory holding its SKILL.md, printed by `python tools/skill.py`). Read it before ROM, text or QA work.

## Commands (run from repo root)
- Build:    `python -X utf8 build.py` -> build/fantastic_children_en.gba (checks the dump against `rom.sha1` first; needs `pip install keystone-engine pillow`). `--marker` = every string `[id] filler`; `--qa ID=text` overrides lines for stress tests (build/qa.gba)
- Lint:     `python -X utf8 tools/lint.py` (width budgets per box, in check.py); budgets from `tools/boxmap.py LOGDIR` (box/region probes `tools/lua/boxlog.lua`, `textput.lua`)
- Check:    `python -X utf8 tools/check.py` (unittest suite in `tests/` + lint; the pre-commit hook runs it). Hooks: `git config core.hooksPath tools/hooks` once per clone.
- Smoke:    `python -X utf8 $SKILL/scripts/emu.py build/fantastic_children_en.gba --out work/qa/smoke --route tools/routes/boot.txt --smoke`
- Warp:     `python -X utf8 $SKILL/scripts/emu.py build/fantastic_children_en.gba --out work/qa/warp --script tools/debug/warp.lua --var "SCENE='<name>'" --frames 3200 --mash 40 --sheet` (scenes: `tools/debug/scenes.gba.txt`, regenerated by `tools/debug/gen_scenes.py`; all scenes checked: `python -X utf8 tools/debug/warp_all.py [--only RE] [--states]`, ≤3 jobs: each Mesen ~590 MB; never ask the user to play to a scene)
- Extract:  `python -X utf8 tools/script_tsv.py extract` (writes missing `script/*.tsv` only; `--force` refreshes jp/ref and keeps en/notes by id; `stats`)
- Release:  `python -X utf8 tools/release.py` (patch + verify; never publish without the user)
- Clean:    `python -X utf8 tools/clean.py` (published projects: lists rebuildable/downloadable files; `--yes` deletes)

## Paths
- Original ROM: `rom/Fantastic Children (Japan).gba` (gitignored; SHA-1 in `rom.sha1`, checked by `tools/check_rom.py`). Emulator: this repo's own MesenCE in `tools/mesen/` (release 2.2.1, https://github.com/nesdev-org/MesenCE/releases/download/2.2.1/Mesen_2.2.1_Windows.zip; gitignored; BIOS `tools/mesen/Firmware/gba_bios.bin` from retrobios `GBA_bios.rom`, SHA-1 300c20df...; settings in `tools/emu-config/`). Savestates: `work/states/`.
- Text: `script/` (TSV). Tables: `tbl/`. Glossary: `glossary.md`. RE notes index: `docs/re/README.md`. Fonts and their licences: `docs/fonts.md`.

## Rulings
- Edit source files (.py .lua .asm .tbl .json) only with the file-edit tool; scripts here read and analyse, never `.replace()` and write back.
- Subagents: dispatch the agent types (translator, reviewer, visual-qa, playtester, graphics) shipped by the plugin as `translate-retro-game:<type>` (Claude Code), `.codex/agents/` (Codex) or `.opencode/agents/` (opencode), never general-purpose: their short tool list cuts each agent's start-up context from ~43k to ~9k tokens.
- The user's decisions, with the options and reasons: `docs/decisions.md`. Read it before asking the user anything; add each new ruling there the same session.
- Player bug reports: GitHub issues (`gh issue list --label bug`). Copy the attached save into `work/states/`, reproduce in the emulator, fix, commit with `Fixes #N`, and update `docs/status.md`.
- Gotchas: the intro plays ~1500 frames before Start skips to the title; the title menu (START GAME / DELETE GAME) is already English.
